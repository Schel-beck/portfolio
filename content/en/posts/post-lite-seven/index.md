## The main goals for this week 
I want to create security for my application focusing on creating secure user log in, registration, authorization and authentication. Im going to make a security package with all these things and more.

## What did i implement in the project?
i made the security package with controller, DAO's, entities, routes and more. In the Security controller i have the registration and login. For the authentication i use JWT tokens which was made following a given example from the schools materials. 

## The decisions i made in the project
I started having user roles in my project where i have ANYONE, USER, ADMIN. ANYONE is before logging in and USER is after logging in. I currently havent created authorization for all my routes. right now authorization is only in the security package, but i do want to make sure that only the admin can use delete routes.
